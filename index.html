Keyboard test notes

Issue
When tabbing, there was no visible sign of which link or button had focus, because the default outline had been removed with outline: none.
Fix
Removed outline: none and added a clear :focus-visible outline to links, buttons and the checkbox. Also added a “Skip to main content” link as the first focusable element.
